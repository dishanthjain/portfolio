# Dishanth Jain — Personal Portfolio Website

A modern, responsive personal portfolio website built to showcase my skills, projects, education, and contact information. The design follows a minimal orange-and-white colour palette with clean typography, subtle visual details, and a user-friendly layout.

## ✨ Features

- **Home Section** — Introduction, developer role, and hero section.
- **About Section** — Education, interests, and career goals.
- **Skills Section** — Technical skills organised into frontend, backend, databases, and tools.
- **Projects Section** — Selected projects with descriptions, technology stacks, and links.
- **Resume Section** — Downloadable resume PDF.
- **Contact Section** — Email, GitHub, LinkedIn, and contact information.
- **Responsive Design** — Optimised layouts for desktop, tablet, and mobile devices.
- **Smooth Navigation** — Scroll navigation between sections and a mobile-friendly menu.
- **Minimal UI** — Orange accents, warm white backgrounds, and clean geometric visuals.

## 🛠️ Tech Stack

- React
- JavaScript
- Vite
- CSS
- Lucide React Icons
- HTML5

## 🚀 Getting Started

### Prerequisites

Install Node.js and npm before running the project.

### Installation

Clone the repository:

```zsh
git clone YOUR_REPOSITORY_URL
```

Navigate to the project directory:

```zsh
cd YOUR_PROJECT_FOLDER
```

Install dependencies:

```zsh
npm install
```

Start the development server:

```zsh
npm run dev
```

Open the local URL displayed in the terminal.

## 🏗️ Production Build

Create an optimised production build:

```zsh
npm run build
```

Preview the production build locally:

```zsh
npm run preview
```

The generated production files will be available in the `dist` directory.
